# Contributing to Lumina

Use Java 25 and Maven 3.9 or newer. Run `mvn -q clean verify` before opening a pull request.

Keep changes focused, add tests for behavior, and preserve Lumina's zero author-written
HTML/CSS/JavaScript invariant. UI changes must satisfy the UX constitution checklist in
`docs/superpowers/specs/2026-08-01-lumina-ux-constitution-checklist.md`.
